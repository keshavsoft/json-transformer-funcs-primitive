ENGINE 1 · ONE ELEMENT

Primitive Template Engine

Resolve one template against one data object to produce one JSON element tree.

Responsibility

The primitive engine resolves one template using one data object and returns a resolved JSON element tree. It fills dynamic values in textContent, attributes, and nested children; it does not iterate a source collection or assemble a table grid.

Input → transformation → output

One data object+One JSON template→One resolved element tree
data:     { "label": "Save", "style": "primary" }
template: { "tagName": "button",
            "textContent": "${label}",
            "attributes": { "class": "btn-${style}" } }
result:   { "tagName": "button",
            "textContent": "Save",
            "attributes": { "class": "btn-primary" } }

Illustrative contract example; the engine's special tokens and recursive child handling are defined by its source implementation.

Place in the family

The collection and grid engines use this engine as their lower-level template resolver. The primitive has no need to know whether its output will become a table cell, option, button, or another element shape.
