1. The Mental Model: The Data & The Mold

In modern headless web engineering, user interfaces should not be assembled through brittle string concatenation or manual DOM mutations. Instead, UI components are declared as clean, serializable JSON abstract syntax trees (ASTs).

🏺
1. The Mold
inTemplate • The Blueprint
A static JSON specification of the element node. Contains ${placeholder} slots in attributes, textContent, or nested children.
💧
2. The Filling
inElement • The Data
A plain dictionary of dynamic values (CSS classnames, IDs, labels, row data) passed in at execution time.
✨
3. The Formed Node
applyTemplate • The Result
A brand new, structurally cloned AST with all slots filled. Zero side effects, complete immutability, executing in under 0.1ms.
🌲
4. Global Tree
window.ks • Family Namespace
Automatically organized in window.ks.transformerFuncs.primitive with runtime metadata and version inspection.
The Primitive Principle: applyTemplate is the atomic unit of the entire transformation pipeline. It does not iterate over external arrays or reshape database schemas. It operates purely at the single-element boundary: one dictionary fills one template.

2. Where Primitive Sits in the KeshavSoft Ecosystem

The KeshavSoft transformation architecture is organized into strict mathematical cardinalities:

Engine Package Cardinality Primary Role Status
json-transformer-funcs-primitive 0D / Atom (1 → 1) Fills dynamic values into a single element node template. v1.9.0 Active
json-transformer-funcs-one-dimension 1D / Linear (N → N) Maps a collection of data objects across a row template. Ecosystem
json-transformer-funcs-two-dimensions 2D / Matrix (M × N → Grid) Transforms matrix data across columns and rows into a complete table. Ecosystem
json-renderers-build-form Application / Spec High-level form builder assembling cards, headers, bodies, and footers. Consumer

3. Quick Peek: How Simple It Is

Using native ES Modules:

import applyTemplate from "json-transformer-funcs-primitive";

const data = {
  cardClass: "card shadow-sm border-0",
  title: "User Profile",
  buttonClass: "btn btn-primary"
};

const template = {
  tagName: "div",
  attributes: { class: "${cardClass}" },
  children: [
    { tagName: "h4", textContent: "${title}" },
    { tagName: "button", attributes: { class: "${buttonClass}" }, textContent: "Edit" }
  ]
};

const result = applyTemplate(data, template);

Or directly in the browser via the new global family tree:

// Direct shortcut or namespaced tree:
const result = window.ks.applyTemplate(data, template);
// or:
const result = window.ks.transformerFuncs.primitive.applyTemplate(data, template);
