Enterprise Cookbook

Real-world JSON-to-DOM templates for input fields, action toolbars, cards, modals, and global tree consumers.

Recipe 1: Form Input Field with Validation State

Binds dynamic IDs, label text, feedback messages, and validation classes in a single pass:

import applyTemplate from "json-transformer-funcs-primitive";

const fieldData = {
  fieldId: "user-email",
  fieldName: "email",
  fieldLabel: "Corporate Email Address",
  placeholderText: "name@company.com",
  inputClass: "form-control is-valid",
  feedbackClass: "valid-feedback",
  feedbackText: "Looks good!"
};

const fieldTemplate = {
  tagName: "div",
  attributes: { class: "mb-3" },
  children: [
    {
      tagName: "label",
      attributes: { for: "${fieldId}", class: "form-label fw-semibold" },
      textContent: "${fieldLabel}"
    },
    {
      tagName: "input",
      attributes: {
        type: "email",
        id: "${fieldId}",
        name: "${fieldName}",
        class: "${inputClass}",
        placeholder: "${placeholderText}"
      }
    },
    {
      tagName: "div",
      attributes: { class: "${feedbackClass}" },
      textContent: "${feedbackText}"
    }
  ]
};

const result = applyTemplate(fieldData, fieldTemplate);

Recipe 2: Dynamic Action Button Group

Demonstrates how one data dictionary simultaneously themes primary and secondary actions:

const buttonData = {
  wrapperClass: "btn-group shadow-sm",
  primaryClass: "btn btn-primary px-4",
  secondaryClass: "btn btn-outline-secondary",
  primaryAction: "Save Contact",
  secondaryAction: "Discard Changes"
};

const buttonTemplate = {
  tagName: "div",
  attributes: { class: "${wrapperClass}", role: "group" },
  children: [
    {
      tagName: "button",
      attributes: { type: "submit", class: "${primaryClass}" },
      textContent: "${primaryAction}"
    },
    {
      tagName: "button",
      attributes: { type: "button", class: "${secondaryClass}" },
      textContent: "${secondaryAction}"
    }
  ]
};

const result = applyTemplate(buttonData, buttonTemplate);

Recipe 3: Dashboard KPI Stat Card with ${agg:count}

Combines title metadata with automatic numeric calculation of pending rows:

const kpiData = {
  cardClass: "card shadow-sm border-0 h-100",
  title: "Pending Claims",
  badgeClass: "badge bg-danger rounded-pill",
  noteText: "Requires immediate underwriting review",
  rowData: [
    { id: 101, user: "Alice" },
    { id: 102, user: "Bob" },
    { id: 103, user: "Charlie" },
    { id: 104, user: "Diana" }
  ]
};

const kpiTemplate = {
  tagName: "div",
  attributes: { class: "${cardClass}" },
  children: [
    {
      tagName: "div",
      attributes: { class: "card-body" },
      children: [
        {
          tagName: "div",
          attributes: { class: "d-flex justify-content-between align-items-center mb-2" },
          children: [
            { tagName: "h6", attributes: { class: "text-muted mb-0" }, textContent: "${title}" },
            { tagName: "span", attributes: { class: "${badgeClass}" }, textContent: "${agg:count}" }
          ]
        },
        { tagName: "p", attributes: { class: "small text-secondary mb-0" }, textContent: "${noteText}" }
      ]
    }
  ]
};

const result = applyTemplate(kpiData, kpiTemplate);
// result.children[0].children[0].children[1].textContent === 4

Recipe 4: Consuming via window.ks.transformerFuncs.primitive

In microfrontend architectures, child remotes consume the shared primitive transformer from the host shell via the global tree: 

// In a Microfrontend Remote:
function renderRemoteCard(containerEl, model) {
  // Discover host primitive engine:
  const transformer = window.ks?.transformerFuncs?.primitive?.applyTemplate 
    || window.ks?.applyTemplate;

  if (!transformer) {
    throw new Error("KeshavSoft primitive transformer not found on window.ks!");
  }

  const template = {
    tagName: "div",
    attributes: { class: "alert alert-${alertType}" },
    textContent: "${alertMessage}"
  };

  const ast = transformer(model, template);
  // ast is now ready for DOM hydration!
  return ast;
}
