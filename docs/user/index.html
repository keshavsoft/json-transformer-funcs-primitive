User Guide API & Usage

Learn how to configure data dictionaries, author templates, and leverage pure token interpolation.

1. The Function Contract

import applyTemplate from "json-transformer-funcs-primitive";

const resolved = applyTemplate(inElement, inTemplate, showLog);
Argument Type Obligation Description
inElement Plain Object Required A dictionary of keys and values used to replace matching ${key} tokens.
inTemplate Object | String Required The JSON-to-DOM AST node or string template containing ${placeholder} slots.
showLog Boolean Optional When true, outputs debugging telemetry to console.log.

2. Guard Rails & Exceptions

The primitive engine enforces strict typing at the boundary to eliminate silent failures downstream. The following table lists the guard checks executed before any parsing occurs:

Input Condition Error Thrown Design Reason
inTemplate === null || undefined TypeError: inTemplate is required Cannot interpolate into an empty or unprovided template.
typeof inTemplate !== "object" && !== "string" TypeError: inTemplate must be an object or string Primitives like numbers or booleans cannot serve as templates.
!inElement || typeof inElement !== "object" TypeError: inElement must be an object Data values must be supplied as a lookup dictionary.
Array.isArray(inElement) TypeError: inElement must be an object Primitive takes 1 object. Arrays must be processed by the 1D engine.

3. Absolute Immutability

A core invariant of the KeshavSoft ecosystem is that templates must remain untouchable. When you run: 

const result = applyTemplate(data, template);

The engine calls structuredClone(localTemplate) upfront. Your original template reference is never altered in memory, allowing you to reuse the exact same template across thousands of rows or requests safely without cache pollution.
