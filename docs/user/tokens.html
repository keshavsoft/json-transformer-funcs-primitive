Token Reference

Comprehensive guide to standard placeholders, multi-token combinations, and built-in typed special tokens.

1. Standard Tokens: ${key}

The engine scans string attributes and textContent using the regular expression /\$\{(\w+)\}/g. Whenever a key inside ${key} is defined in the data dictionary (inElement[key] !== undefined), the token is replaced with its string representation.

Multiple Tokens in One String

A single attribute or text string can combine multiple tokens seamlessly:

const data = {
  colWidth: "col-md-6",
  spacing: "mb-3",
  align: "text-center"
};

const template = {
  tagName: "div",
  attributes: {
    class: "${colWidth} ${spacing} ${align}"
  }
};

const result = applyTemplate(data, template);
// result.attributes.class === "col-md-6 mb-3 text-center"
The Unmatched Token Invariant: If a token does not exist in inElement (e.g. undefined), the token is left intact: ${unknownKey}. This enables progressive multi-pass transformations where upstream engines fill element tokens and downstream engines fill column/row tokens later!

2. Special Built-in Tokens

For enterprise tables, summary cards, and aggregated counters, the engine provides two native tokens that return typed values instead of plain strings:

A. ${agg:count} • Numeric Aggregate Count

When a string template is exactly "${agg:count}" and inElement.rowData is an Array, the engine returns the numeric length of the array (not a string). 

const data = {
  rowData: ["Claim #101", "Claim #102", "Claim #105"]
};

const template = {
  tagName: "span",
  attributes: { class: "badge bg-info" },
  textContent: "${agg:count}"
};

const result = applyTemplate(data, template);
// result.textContent === 3 (typeof number)

B. ${rowValue} • Raw Data Pass-Through

When a string template is exactly "${rowValue}" and inElement.rowData exists, the engine returns the underlying rowData value directly (including objects or primitives). 

const data = {
  rowData: { userId: 90210, role: "Administrator", tier: "Gold" }
};

const template = "${rowValue}";

const result = applyTemplate(data, template);
// result === { userId: 90210, role: "Administrator", tier: "Gold" }
