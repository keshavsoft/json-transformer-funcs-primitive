Token Reference Syntax & Rules

Comprehensive guide to standard tokens, multi-token interpolation, and built-in special tokens.

1. Standard Tokens: ${key}

The engine evaluates placeholders using regular expression matching: /\$\{(\w+)\}/g. Whenever a key inside ${key} exists in the supplied data object (inElement[key] !== undefined), the token is replaced with its string representation.

Multiple Tokens in One String

A single attribute or text string can contain multiple placeholders:

const data = {
  colWidth: "col-md-6",
  spacing: "mb-3",
  align: "text-center"
};

const template = {
  tagName: "div",
  attributes: {
    class: "${colWidth} ${spacing} ${align}"
  }
};

const result = applyTemplate(data, template);
// result.attributes.class === "col-md-6 mb-3 text-center"
Unmatched Token Invariant: If a token does not exist in inElement (is undefined), the token is left as-is (e.g. ${unknownKey}). This allows multi-pass transformations where later pipelines can fill in downstream tokens!

2. Special Built-in Tokens

For enterprise tables and summary cards, the engine provides two native tokens that return typed values:

A. ${agg:count} • Numeric Count

When a string template is exactly "${agg:count}" and inElement.rowData is an Array, the engine returns the numeric length of the array (not a string). 

const data = {
  rowData: ["Order 1", "Order 2", "Order 3"]
};

const template = {
  tagName: "span",
  attributes: { class: "badge bg-info" },
  textContent: "${agg:count}"
};

const result = applyTemplate(data, template);
// result.textContent === 3 (typeof number)

B. ${rowValue} • Raw Object Extraction

When a template is exactly "${rowValue}" and inElement.rowData exists, the engine returns the raw value directly, even if it is a complex nested object or array: 

const data = {
  rowData: { id: 101, name: "Product A", price: 29.99 }
};

const result = applyTemplate(data, "${rowValue}");
// result === { id: 101, name: "Product A", price: 29.99 }

3. Where Tokens Can Be Placed

Target Supported Syntax Engine Behavior
attributes class="${cardClass}", id="${formId}", data-* Recursively walks all attribute keys and values. Supports nested attribute objects.
textContent "Welcome, ${name}!" Interpolates the inner text of tags.
children Nested array of tags Recursively executes applyTemplate down the entire branch.
Root String applyTemplate(data, "${myToken}") Returns interpolated string directly without requiring a wrapper object.
