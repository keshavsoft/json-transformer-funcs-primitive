Developer Guide Engine Internals

A deep architectural tour of the v8 engine pipeline, guard guarantees, and recursive tree resolution.

1. The 5-Module Pipeline

The engine is structured into five single-responsibility modules inside src/v8/:

``` startFunc(inElement, inTemplate) │ ▼ guardFunc(guard.js) │ ▼ structuredClone(inTemplate) │ ┌───────────────────────┼───────────────────────┐ ▼ ▼ ▼ forAttributes forTextContent forChildren │ │ │ └───────────────────────┼───────────────────────┘ ▼ commonReplace(commonReplace.js) │ ▼ Resolved JSON AST ```

2. Module Breakdown

A. guard/guard.js • The Gatekeeper

Validates arguments prior to execution. If inTemplate is null, undefined, or a non-object primitive, or if inElement is an array or non-object, it halts immediately with a descriptive TypeError.

B. src/v8/index.js • The Orchestrator

Immediately assigns inputs to localElement and localTemplate (respecting the KeshavSoft in/local parameter convention). It deep clones the template via structuredClone and dispatches:

  • If string → calls commonReplace.
  • If textContent exists → calls forTextContent.
  • If attributes exists → calls forAttributes.
  • If children exists → calls forChildren.

C. commonReplace.js • The Interpolation Core

Executes regular expression replacement on string values: 

inStringTemplate.replace(/\$\{(\w+)\}/g, (match, key) => {
    return inElement[key] !== undefined ? inElement[key] : match;
});

Additionally handles the two specialized token short-circuits:

  • ${agg:count}: Returns numeric count from inElement.rowData.length.
  • ${rowValue}: Returns raw value from inElement.rowData.

D. forAttributes/index.js • Attribute Walker

Iterates over the attributes key-value dictionary and recursively calls the orchestrator for each value. This ensures nested attributes or complex attribute configs resolve cleanly.

E. forChildren/index.js • Recursive Child Mapper

Iterates over the children array: 

const newChildren = localTemplateChildren.map(element => {
    return parentIndex(inElement, element);
});

3. Test Verification Suite

To run the complete verification suite verifying single elements, nested card structures, special tokens, and all guard assertions: 

npm test
