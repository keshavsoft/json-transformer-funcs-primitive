🛠️ Internals v9 Engine

Developer Internals

A deep architectural tour of the v9 engine pipeline, immutability guarantees, fail-safe removal, and registerGlobal design.

1. The v9 Engine Pipeline

The engine is structured into modular, single-responsibility units inside src/v9/: 

                        startFunc(inElement, inTemplate, showLog)
                                       │
                                       ▼
                              guardFunc(guard/index.js)
                                       │
                                       ▼
                          structuredClone(inTemplate)
                                       │
           ┌───────────────────────────┼───────────────────────────┐
           ▼                           ▼                           ▼
     forAttributes               forTextContent               forChildren
           │                           │                           │
           └───────────────────────────┼───────────────────────────┘
                                       ▼
                         commonReplace(commonReplace.js)
                                       │
                                       ▼
                          Resolved Immutable Element AST
                                       │
                                       ▼
                         registerGlobal(registerGlobal/index.js)
                                       │
                                       ▼
                           window.ks Family Tree

2. Module Breakdown

A. src/v9/registerGlobal/meta.js • The Identity Contract

Provides the immutable identity of the package for runtime telemetry and microfrontend inspection: 

export const meta = {
    name: "json-transformer-funcs-primitive",
    version: "1.9.0"
};

export default meta;

B. src/v9/registerGlobal/index.js • The Tree Registrant

Attaches the function to the global scope cleanly and concisely: 

import meta from "./meta.js";

const registerGlobal = (definition) => {
    if (typeof globalThis === "undefined" || !definition) return;

    globalThis.ks ??= {};

    // Direct access shortcut
    globalThis.ks.applyTemplate ??= definition;

    // Transformer funcs family tree
    globalThis.ks.transformerFuncs ??= {};
    globalThis.ks.transformerFuncs.primitive = {
        meta,
        applyTemplate: definition
    };

    // Full package key
    globalThis.ks["json-transformer-funcs-primitive"] = {
        meta,
        applyTemplate: definition
    };
};

export { registerGlobal, meta };
export default registerGlobal;
Design Rationale — Why No Over-Engineered Fail-Safes? In previous revisions, defensive checks included layers of try-catch blocks, window existence validations, and type-guards. In v9, we follow the modern JS standard: 1. globalThis is universally standard across all ES2020 runtimes (Browser, Node, Deno, Bun, Cloudflare Workers). 2. Nullish coalescing assignment (??=) natively prevents overwriting existing namespaces while creating missing containers in 1 CPU instruction.

C. guard/guard.js • The Gatekeeper

Validates arguments prior to execution. If inTemplate is null, undefined, or a non-object primitive, or if inElement is an array or non-object, it halts immediately with a descriptive TypeError.

D. src/v9/index.js • The Orchestrator

Immediately assigns inputs to localElement and localTemplate (respecting the KeshavSoft in/local parameter convention). It deep clones the template via structuredClone and dispatches:

  • If string → calls commonReplace.
  • If textContent exists → calls forTextContent.
  • If attributes exists → calls forAttributes.
  • If children exists → calls forChildren.

E. commonReplace.js • The Interpolation Core

Executes regular expression replacement on string values: 

inStringTemplate.replace(/\$\{(\w+)\}/g, (match, key) => {
    return inElement[key] !== undefined ? inElement[key] : match;
});

3. Recursive Child Resolution

When a node contains a children array, forChildren iterates through each item:

  1. If the child is a nested object, it recursively invokes startFunc(localElement, child).
  2. If the child is a string, it calls commonReplace(child, localElement).
  3. If the child is a primitive or null, it preserves it verbatim.

4. Verification & Testing Suite

The package maintains 100% test coverage through samples/runAll.js:

  • Step 1: Simple Element interpolation.
  • Step 2: Nested Card Component tree resolution.
  • Step 3: Special Tokens (${agg:count} and ${rowValue}).
  • Step 4: Guard Validations (type error assertions).
  • Step 5: Global Registration (verifying globalThis.ks.applyTemplate and globalThis.ks.transformerFuncs.primitive).
