The window.ks Family Tree

How json-transformer-funcs-primitive self-registers into a structured, unified namespace without global pollution.

1. The Problem: Global Pollution vs Discovery

In modern enterprise frontend development, components and renderers frequently need access to data transformation functions across boundaries (e.g., microfrontends, web components, browser consoles, and legacy bundles).

Common anti-patterns either dump dozens of loose function names directly onto window (e.g. window.applyTemplate, window.transformRow, window.transformTable), risking collisions, or encapsulate them so heavily that external devtools and runtime pipelines cannot discover them.

Starting in v1.9.0, json-transformer-funcs-primitive introduces an elegant family-tree pattern anchored on window.ks (or universally globalThis.ks).

2. The KeshavSoft Transformer Hierarchy

When you import json-transformer-funcs-primitive in a browser or Node runtime, the module automatically maps its capabilities into three distinct access levels:

🌐 globalThis.ks (window.ks) Root Namespace
⚡ applyTemplate(inElement, inTemplate) Direct Shortcut
Convenient top-level alias for rapid scripting and console evaluations.
🌲 transformerFuncs Family Tree
The unified branch housing all KeshavSoft data-to-DOM transformation engines.
⚛️ primitive Active (0D Atom)
{ meta: { name, version }, applyTemplate }
📏 oneDimension Ecosystem (1D Row)
Linear array-to-row transformation engine.
📊 twoDimensions Ecosystem (2D Matrix)
Matrix grid & multi-column transformation engine.
📦 ["json-transformer-funcs-primitive"] Package Key
Exact npm package name key providing canonical lookup for build plugins and diagnostic tooling.

3. Inside the registerGlobal/ Architecture

The global registration logic is kept clean, isolated, and completely separated from the core transformation algorithm:

A. The Metadata Contract: meta.js

Located at src/v9/registerGlobal/meta.js, this single-responsibility file publishes the package identity: 

export const meta = {
    name: "json-transformer-funcs-primitive",
    version: "1.9.0"
};

export default meta;

B. The Non-Destructive Registrant: index.js

Located at src/v9/registerGlobal/index.js, the registrant uses the ES2020 nullish coalescing assignment operator (??=) to initialize the tree safely without overwriting pre-existing structures: 

import meta from "./meta.js";

const registerGlobal = (definition) => {
    if (typeof globalThis === "undefined" || !definition) return;

    globalThis.ks ??= {};

    // 1. Direct access shortcut
    globalThis.ks.applyTemplate ??= definition;

    // 2. Transformer funcs family tree
    globalThis.ks.transformerFuncs ??= {};
    globalThis.ks.transformerFuncs.primitive = {
        meta,
        applyTemplate: definition
    };

    // 3. Full package name key
    globalThis.ks["json-transformer-funcs-primitive"] = {
        meta,
        applyTemplate: definition
    };
};

export { registerGlobal, meta };
export default registerGlobal;
Zero Fail-Safe Pollution: Notice how simple and clean this function is! We avoid nested try-catches and 20 defensive checks. By relying on native globalThis and ??=, it executes in sub-microseconds and guarantees immutability across the family tree.

4. Universal Runtime: Browser, Node.js & SSR

Why globalThis instead of a raw window reference?

Environment What globalThis points to Safety Result
Modern Browser window window.ks.applyTemplate is immediately available in console and scripts.
Node.js / Vitest / Jest global Tests run smoothly with global.ks without throwing ReferenceError: window is not defined.
Web Worker self Workers can perform background JSON transforms with zero overhead.

5. How to Consume via the Global Tree

Pattern 1: Direct Ergonomic Call

// Any browser script or devtools console
const data = { title: "Dashboard", badgeClass: "badge bg-primary" };
const template = { tagName: "h3", attributes: { class: "${badgeClass}" }, textContent: "${title}" };

// Call directly from window.ks:
const result = window.ks.applyTemplate(data, template);
console.log(result);

Pattern 2: Family Tree Lookup with Version Introspection

// Check version of the primitive engine at runtime
const primitiveEngine = window.ks.transformerFuncs.primitive;

console.log(`Using ${primitiveEngine.meta.name} v${primitiveEngine.meta.version}`);

// Transform using the namespaced engine:
const resolvedNode = primitiveEngine.applyTemplate(data, template);
